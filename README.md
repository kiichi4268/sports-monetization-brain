# sports-monetization-brain

スポーツ事業 収益化・戦略ナレッジベース

> 本リポジトリは **SNS自動投稿システムとは完全に分離された**「収益戦略・コンテンツ開発・市場リサーチ・AIプロンプト・運用手順書」専用のナレッジベースです。
> コード（自動投稿の実装）はここに置かず、**「何を・なぜ・どの順番で」やるか** の意思決定と手順だけを蓄積します。

## 2. 全体ロードマップ（6ヶ月）

```
Month 1 ──── Month 2 ──── Month 3 ──── Month 4 ──── Month 5 ──── Month 6
[Phase 1 基盤]  [Phase 2 初収益]   [Phase 3 拡大]            [Phase 4 安定20万]
 イベント定期化   note第1弾販売      note第2-3弾/バンドル      協賛 月1社定着
 LINE導線構築    ブログ20記事       ブログ50記事/内部リンク    ブログ70記事+リライト
 競合/コート調査  協賛先リスト50社   協賛 初受注               全柱KPIの週次運用
```

| Phase | 期間 | 主目的 | 完了条件（Exit Criteria） | 月利益の目安 |
|---|---|---|---|---|
| **1. 基盤構築** | 1ヶ月目 | 集客・予約・参加証の自動化と、月2回のイベント定期開催 | LINE友だち100人／イベント2回開催／コート確保フロー確立 | 0〜2万円 |
| **2. 初収益化** | 2〜3ヶ月目 | 有料note第1弾の販売とブログ記事の量産 | note累計30部／ブログ20記事公開／ASP提携10件 | 5〜10万円 |
| **3. 拡大** | 3〜4ヶ月目 | noteの商品ラインナップ化、協賛初受注 | note月40部／ブログ月1万PV／協賛1社受注 | 10〜15万円 |
| **4. 安定化** | 5〜6ヶ月目 | 全柱をKPIで回し、20万円を3ヶ月連続達成 | 月利益20万円 × 3ヶ月連続 | 18〜23万円 |

## 3. 月20万円達成までのマスター手順書

> 各ステップは「やること → 参照ファイル → 完了チェック」の順に記載。上から順番に実行してください。

### STEP 1：市場と競合を知る（1週目）
- [ ] `prompts/01_research_analyst.md` を使って都内の競合サークル10件を分析
- [ ] 結果を `research/competitor_analysis.md` の比較表に記入
- [ ] 自分のポジション（価格帯・レベル帯・エリア・独自価値）を1行で決める
  - 例：「渋谷・新宿エリアで、**完全初心者×一人参加9割**の1,500円バドミントン会」

### STEP 2：ペルソナと動線を確定する（1週目）
- [ ] `strategy/target_persona.md` のメインペルソナを自分の言葉で書き換える
- [ ] 心理ハードル Top5 に対する「解消策」を募集文に反映する

### STEP 3：コートを確保する（1〜2週目）
- [ ] `research/court_reservation_hack.md` に沿って区立体育館の利用者登録（2〜3区）
- [ ] 抽選スケジュールをカレンダー登録、翌月分を申し込む
- [ ] 抽選外れ時の代替（個人開放／民間コート）を必ず1つ用意

### STEP 4：LINE導線と参加証の自動化（2週目）
- [ ] `execution_guides/autosns_line_setup.md` に沿ってLINE公式＋エルメを設定
- [ ] 「友だち追加 → 予約 → 参加証発行 → 前日リマインド → 参加後アンケート」を自動化
- [ ] テストアカウントで一連の動作を確認

### STEP 5：イベントを月2回開催（3〜4週目〜継続）
- [ ] 参加費・定員・コストを `strategy/revenue_model.md` の計算式で事前検証（利益が出ない回は開催しない）
- [ ] 参加後アンケートで「困りごと・知りたいこと」を収集 → note・ブログのネタ帳へ

### STEP 6：有料note第1弾を販売（2ヶ月目）
- [ ] `prompts/02_note_creator.md` で企画3案 → 1案に絞る
- [ ] `execution_guides/note_launch_guide.md` に沿って公開・LINE配信・SNS告知
- [ ] 目標：初週10部、初月30部

### STEP 7：ブログを量産しストック化（2ヶ月目〜継続）
- [ ] `execution_guides/wordpress_monetization.md` で初期設定・PR表記を完了
- [ ] `research/affiliate_master_list.md` でASP提携
- [ ] `prompts/03_blog_architect.md` で週3記事ペースを維持

### STEP 8：協賛営業（3ヶ月目〜）
- [ ] 実績（累計参加者数・LINE友だち数・SNSフォロワー・アンケート結果）を1枚にまとめる
- [ ] `prompts/04_sponsor_pitcher.md` で提案書・営業文を作成し、週5社にアプローチ

### STEP 9：週次で回す（全期間）
- [ ] 毎週月曜に `prompts/05_biz_dev_manager.md` へKPIを入力し、今週のタスクを自動生成
- [ ] 下記「週次アクションプラン」に沿って実行

## 5. 運用ルール

- **数字で判断する**：感覚ではなく `strategy/revenue_model.md` のKPIで意思決定する
- **一次情報が武器**：イベント現場の声・写真・失敗談を、note・ブログ・協賛提案に必ず再利用する
- **法令・規約順守**：景品表示法（ステマ規制）に基づくPR表記、各施設の利用規約、ASP規約、LINE/note規約を守る
- **更新ルール**：施策の結果は該当ファイルに追記し、学びは日付付きで残す（`git log` が意思決定の履歴になる）
