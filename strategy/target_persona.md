## 4. 動線設計（カスタマージャーニー）

```
[認知]            [興味]              [行動]             [体験]            [リピート/購入]
SNS投稿     →   プロフィール/     →  LINE友だち追加   →  イベント参加   →  次回予約
検索(ブログ)     イベントページ        (特典で後押し)       (参加証で受付)     note購入
Googleマップ                          3タップ予約                           アフィリ商品購入
                                                                             紹介・口コミ
```

### 各段階の設計

| 段階 | 接点 | KPI | 施策 |
|---|---|---|---|
| 認知 | Instagram／X／TikTok／ブログ検索 | インプレッション・PV | イベントの「雰囲気が伝わる」短尺動画、初心者向けSEO記事 |
| 興味 | プロフィール／ブログ記事 | プロフィールアクセス率 | 固定投稿に「初めての方へ」まとめ、ハードル解消FAQ |
| 行動 | **LINE友だち追加** | 友だち追加率 | 追加特典（例：「都内コート予約カレンダー」PDF）、追加後すぐ予約導線 |
| 予約 | LINE（エルメ） | 予約率 | 3タップ予約、残席表示で希少性 |
| 参加 | デジタル参加証 | 参加率（予約→来場） | 前日・当日リマインド、参加証で受付を簡略化 |
| 体験 | イベント現場 | 満足度・NPS | 名札・ペアリング・写真撮影（同意制） |
| 参加後 | LINEアンケート | 回答率 | 回答特典＝次回割引・noteのクーポン |
| リピート | LINEセグメント配信 | リピート率 | 参加回数タグで「常連限定枠」 |
| 購入 | note／ブログ | 購入率・CVR | 参加者アンケートで出た悩みを商品化 |
| 紹介 | 友だち紹介 | 紹介数 | 紹介者・被紹介者ともに割引 |

### LINEセグメント（タグ）設計

| タグ | 付与条件 | 配信内容 |
|---|---|---|
| `新規_未参加` | 友だち追加のみ | 初心者向け案内・不安解消FAQ・初回割引 |
| `参加_1回` | 初参加 | お礼・写真共有・次回案内 |
| `参加_3回以上` | 常連 | 先行予約・常連限定イベント・運営スタッフ募集 |
| `興味_上達` | アンケートで選択 | 練習ノウハウnote・スクール案内 |
| `興味_運営` | アンケートで選択 | 運営ノウハウnote（高単価） |
| `興味_健康` | アンケートで選択 | プロテイン・ジム記事 |
| `note購入者` | 購入報告フォーム | 上位版案内・レビュー依頼 |
