## 1. イベント参加費利益

### 計算式

```
1回あたり利益 = (参加費 × 参加人数) − (施設利用料 + 用具消耗品 + 保険料 + 決済手数料 + その他)
月間利益     = 1回あたり利益 × 月間開催回数
損益分岐人数 = 固定コスト(施設+用具+保険) ÷ (参加費 − 1人あたり変動費)
```

### 試算例（バドミントン・区立体育館 2時間）

| 項目 | 金額 | 備考 |
|---|---|---|
| 参加費 | 1,500円 × 16人 = 24,000円 | |
| 施設利用料 | −6,000円 | 区立体育館の面貸し（区・時間帯で大きく異なる） |
| 用具消耗品 | −2,500円 | シャトル等 |
| 保険料 | −800円 | 団体保険を按分 |
| 決済手数料 | −700円 | オンライン決済時（約3%） |
| **1回あたり利益** | **約14,000円** | |
| 月2回開催 | **約28,000円** | → 目標 1〜3万円の上限側 |

### 必要KPI

| KPI | 目標値 | 改善レバー |
|---|---|---|
| 月間開催回数 | 2〜3回 | コート確保力（`research/court_reservation_hack.md`） |
| 1回あたり参加人数 | 定員の85%以上 | LINE事前告知・リマインド・キャンセル待ち |
| 当日キャンセル率 | 5%以下 | 事前決済・前日リマインド |
| リピート率 | 50%以上 | 参加後フォロー・次回優先案内 |
| 損益分岐人数 | 7人以下に抑える | 施設費の安い枠を確保 |

> **重要**：イベント自体は「利益の柱」というより **note・ブログ・協賛の“一次情報と信頼の源泉”**。赤字の回は作らないが、利益最大化より **参加者満足度とリピート** を優先する。

## 2. 有料note

### 計算式

```
note純売上 = Σ(価格 × 販売部数) × (1 − 手数料率)
販売部数   = 流入数(LINE/SNS/ブログ/note内) × 購入率
手数料率   ≒ 15%前後（決済手数料＋プラットフォーム利用料。最新の料率は note 公式で確認）
```

### 試算例（目標 9万円）

| 商品 | 価格 | 月間部数 | 売上 |
|---|---|---|---|
| A. 入門ノウハウ（例：都内でコートを確実に取る方法） | 1,000円 | 20部 | 20,000円 |
| B. 実践ガイド（例：社会人スポーツサークルの作り方・集客編） | 1,980円 | 25部 | 49,500円 |
| C. 完全版（例：サークル運営で月3万円の利益を出す全手順＋テンプレ） | 3,980円 | 10部 | 39,800円 |
| **総売上** | | **55部** | **109,300円** |
| 手数料（約15%） | | | −16,395円 |
| **純売上** | | | **約92,900円** |

### 必要KPI（ファネル）

| 段階 | KPI | 目標値 |
|---|---|---|
| 認知 | note記事ページ閲覧数（月） | 2,500〜3,000 |
| 興味 | 無料部分の読了率 | 40%以上 |
| 購入 | 購入率（閲覧→購入） | 2%前後 |
| LINE経由 | LINE配信からの購入率 | 5〜10%（友だち数300人で15〜30部） |
| 単価 | 平均購入単価 | 2,000円前後 |
| 継続 | 月間新作 or 大型アップデート | 1本 |

> 単価は 1,000円〜3,980円の **3段階ラインナップ**（入門→実践→完全版）でアップセル動線を作る。

## 3. ブログ（アフィリエイト）

### 計算式

```
月間報酬 = PV × 記事内リンククリック率(CTR) × 成約率(CVR) × 平均報酬単価
         + 広告収益(任意)
```

### 試算例（目標 6万円）

| 項目 | 値 |
|---|---|
| 月間PV | 30,000 |
| アフィリエイトリンクCTR | 3% → 900クリック |
| 成約率（CVR） | 2% → 18件 |
| 平均報酬単価 | 3,500円（プロテイン数百円〜スクール・保険の数千〜1万円超を混合） |
| **アフィリエイト報酬** | **63,000円** |

### カテゴリ別の報酬構成イメージ

| カテゴリ | 想定報酬単価 | 月間件数 | 小計 |
|---|---|---|---|
| スクール・パーソナルジム（無料体験・申込） | 5,000〜15,000円 | 3件 | 約30,000円 |
| スポーツ保険・各種保険相談 | 3,000〜10,000円 | 2件 | 約12,000円 |
| プロテイン・サプリ | 500〜2,000円 | 10件 | 約10,000円 |
| ウェア・シューズ・用具（物販） | 売上の数% | 多数 | 約8,000円 |
| **合計** | | | **約60,000円** |

> 単価は目安。正確な報酬は `research/affiliate_master_list.md` の実案件で管理する。

### 必要KPI

| KPI | 3ヶ月目 | 6ヶ月目 |
|---|---|---|
| 公開記事数（累計） | 30 | 70 |
| 月間PV | 10,000 | 30,000 |
| 収益記事（比較・レビュー・おすすめ）の割合 | 30% | 40% |
| アフィリエイトCTR | 2% | 3% |
| 成約率 | 1.5% | 2% |

## 4. 企業協賛

### 計算式

```
協賛利益 = Σ(協賛金 + 物品提供の換算価値) − 実施コスト(配布・撮影・レポート作成)
受注件数 = アプローチ数 × 商談化率 × 受注率
```

### 協賛メニュー（初期価格案）

| メニュー | 内容 | 価格目安 |
|---|---|---|
| サンプリング協賛 | イベントで商品配布＋アンケート回収 | 1〜2万円／回（＋商品提供） |
| SNS・LINE露出 | 告知投稿・LINE配信での紹介 | 5,000〜1万円／回 |
| ネーミング協賛 | 「〇〇 presents △△カップ」 | 3〜5万円／回 |
| 年間パートナー | 月1回の露出＋レポート | 月2〜3万円 |

### 必要KPI

| KPI | 目標値 |
|---|---|
| 月間アプローチ数 | 20社 |
| 商談化率 | 10%（2社） |
| 受注率（商談→受注） | 50%（1社） |
| 協賛後の継続率 | 50%以上 |
| 提案時に示す実績 | 累計参加者数／LINE友だち数／SNSフォロワー／アンケート回収数 |

## 5. 月20万円の達成パターン（シナリオ）

| シナリオ | ①イベント | ②note | ③ブログ | ④協賛 | 合計 |
|---|---|---|---|---|---|
| 保守的 | 1万 | 8万 | 5万 | 2万 | 16万 |
| **標準（目標）** | **2万** | **9万** | **6万** | **3万** | **20万** |
| 楽観的 | 3万 | 10万 | 7万 | 3万 | 23万 |

### 感度分析：どこを伸ばすと一番効くか
- **note 購入率 +1%**（2%→3%）：閲覧3,000で +30部 ≒ **+5万円** ← 最も効く
- **ブログ PV +10,000**：CTR3%・CVR2%・単価3,500円で ≒ **+2.1万円**
- **イベント 月+1回**：≒ **+1.4万円**
- **協賛 月+1社**：≒ **+2〜3万円**

→ 序盤は **イベント×LINE×note** の連携に集中し、ブログは時間差で効く資産として淡々と積む。
