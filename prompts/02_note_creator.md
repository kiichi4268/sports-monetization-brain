# AI社員 02：有料noteクリエイター

> **役割**：1,000円〜3,980円で売れる有料noteの **企画・タイトル・目次・無料部分（フック）・本文・販売文** を生成する。
> **関連**：`execution_guides/note_launch_guide.md`（公開・販売手順）／`strategy/revenue_model.md`（価格・部数目標）
> **原則**：AIは「構成と下書き」担当。**一次情報（自分の実体験・数字・写真）は必ず人間が入れる**。それが価格の正当性になる。

---

## 入力変数

| 変数 | 説明 | 例 |
|---|---|---|
| `{{THEME}}` | テーマ | 都内の区立体育館で毎月コートを確保する方法 |
| `{{TARGET}}` | 想定読者 | 社会人サークルを立ち上げたい20〜30代 |
| `{{PRICE}}` | 価格 | 1,980円 |
| `{{MY_PROOF}}` | 実績・一次情報 | 半年で24回開催、累計参加者380人、抽選当選率の記録 |
| `{{READER_PAIN}}` | 読者の悩み（アンケート等） | 抽選に外れ続ける、どの区で登録できるか分からない |
| `{{DELIVERABLES}}` | 付録・特典 | 抽選カレンダーテンプレ、募集文テンプレ |
| `{{LENGTH}}` | 想定文字数 | 15,000字 |

### 価格帯の設計指針

| 価格 | 位置づけ | 分量目安 | 必須要素 |
|---|---|---|---|
| 1,000円 | 入門・お試し | 5,000〜8,000字 | 1つの悩みを解決する具体手順 |
| 1,980円 | 実践ガイド | 10,000〜20,000字 | 手順＋実例＋テンプレ1〜2点 |
| 2,980円 | 実践＋事例集 | 20,000字〜 | 失敗談・数値データ・テンプレ複数 |
| 3,980円 | 完全版・バンドル | 30,000字〜 or 複数note | 全工程＋収支表＋テンプレ一式＋アップデート約束 |

## STEP 1：企画プロンプト

```
あなたは、スポーツ×副業ジャンルで累計数千部を売ったnoteプロデューサーです。

# 前提
- テーマ候補：{{THEME}}
- 読者：{{TARGET}}
- 読者の悩み：{{READER_PAIN}}
- 私の実績・一次情報：{{MY_PROOF}}
- 価格帯：1,000円〜3,980円

# タスク
売れる有料noteの企画を3案出してください。各案について：
1. タイトル（32文字以内・数字と具体的ベネフィットを含む）を3パターン
2. サブタイトル（誰の・どんな悩みが・どうなるか）
3. 推奨価格と根拠（上記の価格帯設計に沿って）
4. 「無料では手に入らない理由」＝一次情報の要素
5. 想定購入者の購入動機（3つ）
6. 競合となる無料情報と、それとの差別化ポイント
7. 売れる見込み（高/中/低）と理由

最後に、私の実績から最も売れる1案を推薦し、その理由を述べてください。
```

## STEP 2：目次（構成）プロンプト

```
採用案：{{SELECTED_TITLE}}（価格 {{PRICE}}／想定 {{LENGTH}}）

以下の構成ルールでnoteの目次を作成してください。

# 構成ルール
- 【無料部分】
  1. フック（読者の痛みの言語化 → 共感）
  2. 筆者の実績と信頼性（数字で）
  3. このnoteで得られること（箇条書き5〜7個・ベネフィット表現）
  4. こんな人に向けて／向かない人（正直に）
  5. 目次（有料部分の見出しを全て見せる）
  ―――― ここから有料 ――――
- 【有料部分】
  - 各章は「結論 → 理由 → 具体手順 → 実例（一次情報）→ よくある失敗」の順
  - 読者がすぐ使えるテンプレ・チェックリストを最低{{DELIVERABLES}}含める
  - 最終章：明日からの行動プラン（7日間）
  - あとがき：上位商品／LINEへの導線

# 出力
- 章・節の見出し一覧（H2/H3）
- 各節に「書く内容のメモ」と「私が入れるべき一次情報（例：抽選結果の表、収支の実数）」を併記
- 有料部分の「境界線」の直前に置く一文（続きを読みたくなる“引き”）を3案
```

## STEP 3：無料部分（フック文）プロンプト

```
目次をもとに、無料部分（有料ラインの直前まで）を執筆してください。

# 文体・ルール
- です・ます調、1文は60字以内、スマホで読みやすい改行
- 冒頭3行で「これは自分のことだ」と思わせる
- 実績は具体的な数字で（{{MY_PROOF}}）
- 誇大表現（「絶対」「誰でも確実に」「必ず稼げる」）は使わない
- 「向かない人」を明記して信頼を得る
- 有料ライン直前に“引き”を置く

# フックの型（どれか or 組み合わせ）
A. 失敗談型：「3ヶ月連続で抽選に外れ、メンバーが離れかけました」
B. 数字型：「当選率12% → 68% に上げた申込方法を全部書きます」
C. 問いかけ型：「なぜ同じ区で、毎月コートを取れる団体があるのか？」
D. ビフォーアフター型
```

## STEP 4：有料本文プロンプト（章ごとに実行）

```
第{{N}}章「{{CHAPTER_TITLE}}」を執筆してください。

# 入力（私の一次情報）
{{CHAPTER_FACTS}}

# ルール
- 構成：結論 → 理由 → 具体手順（番号付き） → 実例 → よくある失敗と対策
- 私の一次情報は改変・誇張しない。足りない箇所は【要追記：〇〇】と明示し、捏造しない
- テンプレ・チェックリストはコピペで使える形式（コードブロック or 表）
- 文字数：{{CHAPTER_LENGTH}}字程度
```

## STEP 5：販売文・告知文プロンプト

```
完成したnote「{{TITLE}}」（{{PRICE}}）の販売用テキストを作成してください。

1. note紹介文（記事上部・150字）
2. X投稿 ×3パターン（140字以内、フック型／数字型／体験談型）
3. Instagramキャプション（ハッシュタグ10個）
4. LINE配信文（セグメント：{{SEGMENT}}、300字以内、期間限定価格がある場合は期限を明記）
5. ブログ記事内の紹介ボックス文（100字）
6. 購入者向けのお礼メッセージ＋レビュー依頼文
```

## 品質チェックリスト
- [ ] タイトルに「数字」「具体的ベネフィット」「対象者」のうち2つ以上が入っている
- [ ] 無料部分だけで「この人は本物だ」と分かる実績が書かれている
- [ ] 有料部分に **自分しか書けない一次情報** が各章1つ以上ある
- [ ] 【要追記】が残っていない
- [ ] 誇大表現・断定表現がない（特に「稼げる」系）
- [ ] 末尾にLINE・上位商品への導線がある
