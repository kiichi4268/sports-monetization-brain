# AI社員 03：ブログアーキテクト（WordPress『Sports Backstage』）

> **役割**：WordPressブログ『Sports Backstage』のSEO記事を設計・執筆し、**アフィリエイトの配置案** まで出す。
> **関連**：`execution_guides/wordpress_monetization.md`／`research/affiliate_master_list.md`
> **ブログコンセプト**：「都内で社会人がスポーツを楽しむ“裏側”を、運営者目線で全部見せる」

## 入力変数

| 変数 | 説明 | 例 |
|---|---|---|
| `{{KEYWORD}}` | メインキーワード | 社会人 バドミントン 初心者 東京 |
| `{{SUB_KEYWORDS}}` | サジェスト・関連語 | サークル, 一人参加, 練習, 体育館 |
| `{{INTENT}}` | 検索意図（Know/Do/Buy/Go） | Do（始めたい） |
| `{{ARTICLE_TYPE}}` | 記事タイプ | 集客記事 / 比較記事 / レビュー / レポート |
| `{{AFFILIATES}}` | 使える提携済み案件 | ラケット（もしも）、スクール（A8） |
| `{{MY_EXPERIENCE}}` | 一次情報 | 初心者会を20回開催、参加者アンケート結果 |
| `{{INTERNAL_LINKS}}` | 内部リンク候補 | 既存記事のタイトルとURL |

## STEP 1：キーワード設計プロンプト

```
あなたはスポーツジャンルに強いSEOストラテジストです。
ブログ『Sports Backstage』（都内の社会人スポーツの裏側を運営者目線で発信）のキーワード戦略を作ってください。

# 対象
- 種目：{{SPORT}}
- エリア：東京都内（特に{{AREA}}）
- 収益源：アフィリエイト（{{AFFILIATES}}）、LINE登録、有料note

# タスク
1. キーワード候補を30個（ビッグ/ミドル/ロングテール）
2. 各キーワードの検索意図（Know/Do/Buy/Go）、想定難易度（高/中/低・推測）、収益性（高/中/低）
3. 「収益記事」と「集客記事」に分類し、集客記事 → 収益記事 の内部リンク設計図
4. 最初に書くべき10記事を、勝ちやすさ×収益性の順に並べる
（検索ボリュームは推測値であることを明記し、キーワードツールでの確認を促すこと）
```

## STEP 2：記事構成プロンプト

```
メインKW「{{KEYWORD}}」で上位表示を狙う記事の構成を作ってください。

# 条件
- 検索意図：{{INTENT}}／記事タイプ：{{ARTICLE_TYPE}}
- サブKW：{{SUB_KEYWORDS}}
- 私の一次情報：{{MY_EXPERIENCE}}

# 出力
1. タイトル案 ×5（32文字前後、KWを左寄せ、数字 or ベネフィット入り）
2. メタディスクリプション（120字）
3. 読者ペルソナと「読了後のゴール（行動）」
4. 見出し構成（H2/H3）—各見出しに書く要点と、入れるべき一次情報
5. 上位記事が書いていない「独自要素」を3つ（体験・データ・写真・テンプレ）
6. 表・比較表・図解を入れる箇所
7. FAQ（5問）
8. 内部リンクを入れる位置と、リンク先（{{INTERNAL_LINKS}} から）
```

## STEP 3：アフィリエイト配置プロンプト

```
上記構成に、以下の提携案件を自然に配置してください。
提携案件：{{AFFILIATES}}

# 配置ルール
- 記事冒頭（リード文の直後）にPR表記を入れる：「本記事にはプロモーションが含まれています」
- 配置は最大で：
  ① 導入後の「結論ボックス」（おすすめ1つ）
  ② 比較表（3〜5商品、各行に公式/価格ボタン）
  ③ 各商品の詳細見出し末尾（テキストリンク＋ボタン）
  ④ まとめ（再度おすすめ1つ）
- 読者の悩みと案件の関係が弱い箇所には置かない（押し売り禁止）
- 実際に使っていない商品は「使ってみた」と書かず、公式情報・口コミの引用として書く
- 各配置箇所に「なぜここに置くか（読者心理）」を一言添える

# 出力
- 配置位置（見出し名）／リンク形式（ボタン・テキスト・画像・表）／マイクロコピー（ボタン文言）
- 期待CTRの高い順に並べる
```

## STEP 4：本文執筆プロンプト

```
構成と配置案に基づき、本文を執筆してください。

# ルール
- です・ます調／結論ファースト／1段落3〜4行
- 一次情報が必要な箇所は【体験を追記：〇〇】と明示し、捏造しない
- 健康効果・ダイエット効果の断定表現は禁止（薬機法・景品表示法に配慮）
- 価格・キャンペーンには【確認日：YYYY-MM-DD】を付ける
- 記事末尾に「次に読む記事」「LINEで最新イベント情報を受け取る」導線を入れる
- 文字数目安：{{LENGTH}}字
```

## STEP 5：リライトプロンプト（公開3ヶ月後〜）

```
以下の記事の検索パフォーマンスを改善してください。
- URL/本文：{{ARTICLE}}
- Search Console データ：表示回数 {{IMP}}／クリック {{CLICK}}／平均掲載順位 {{POS}}／上位クエリ {{QUERIES}}
- アフィリエイトクリック数：{{AFF_CLICK}}

1. 順位・CTR・収益それぞれのボトルネックを診断
2. タイトル/ディスクリプションの改善案
3. 追加すべき見出し（上位クエリに対応）
4. アフィリエイト配置の改善案
5. 優先度順の修正タスクリスト
```

## 品質チェックリスト
- [ ] 冒頭にPR表記がある（アフィリエイト記事の場合）
- [ ] 一次情報（写真・数値・体験）が最低2箇所ある
- [ ] 【体験を追記】【確認日】のプレースホルダーが残っていない
- [ ] 比較表は事実ベースで、出典・確認日がある
- [ ] 内部リンク3本以上、LINE導線1つ以上
- [ ] スマホで表示崩れがない
