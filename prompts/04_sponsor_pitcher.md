# AI社員 04：スポンサー・ピッチャー（協賛営業）

> **役割**：企業向けの **協賛提案書・サンプリング営業文・フォローアップ文** を生成し、月1社以上の協賛獲得を目指す。
> **関連**：`strategy/revenue_model.md#4-企業協賛`
> **原則**：企業が欲しいのは「寄付先」ではなく **“狙った層への接点とデータ”**。提案は必ず相手のメリットから書く。

---

## 入力変数

| 変数 | 説明 | 例 |
|---|---|---|
| `{{COMPANY}}` | 企業名 | 〇〇株式会社 |

## STEP 1：企業の課題仮説プロンプト

```
あなたはスポーツマーケティングの法人営業のプロです。
以下の企業について、公開情報から推測できる「マーケティング課題」と「私のイベントと組むメリット」を整理してください。

- 企業：{{COMPANY}}
- 商品：{{PRODUCT}}
- 私の媒体：{{MY_ASSETS}}
- 参加者属性：{{AUDIENCE}}

出力：
1. 企業が今伸ばしたいと思われるターゲット層（推測であることを明記）
2. その層と私の参加者属性の重なり
3. 企業側の担当者が社内稟議で使える「協賛の意義」3点
4. 想定される懸念（費用対効果、ブランド毀損リスク、手間）とその解消策
```

## STEP 2：協賛提案書（A4 2〜3枚相当）プロンプト

```
{{COMPANY}} 様向けの協賛提案書を作成してください。

# 構成
1. 表紙：タイトル「{{PRODUCT}} × {{EVENT_NAME}} サンプリング協賛のご提案」
2. ご提案の概要（3行）
3. 私たちについて：活動概要と実績（{{MY_ASSETS}}）を数字で
4. 参加者プロフィール：{{AUDIENCE}}（グラフ化しやすい表で）
5. 協賛メニュー：{{MENU}}
   - 提供内容／露出内容／実施レポートの内容
6. 協賛のメリット（企業視点で3つ）
   - 例：ターゲット層への直接接点、商品フィードバックの取得、SNS二次拡散
7. 実施の流れとスケジュール
8. 実施後レポートのサンプル項目（配布数・アンケート回答数・満足度・SNS投稿数・写真）
9. 費用（税込/税別を明記）とお支払い条件
10. お問い合わせ先

# トーン
- 丁寧なビジネス文書。誇張しない。数値は私が入力したもののみ使用
- 不明な数値は【要記入】とする
```

## STEP 3：初回アプローチ文（メール／問い合わせフォーム／DM）プロンプト

```
{{COMPANY}} の{{CONTACT_CHANNEL}}に送る初回アプローチ文を作成してください。

# 条件
- 300〜400字（DMの場合は200字）
- 件名（メールの場合）を3案
- 1文目で「誰が・何の提案か」を明確に
- 相手のメリットを数字で1つ以上
- 依頼は1つだけ（例：「資料をお送りしてもよろしいでしょうか」）
- 押し売り感を出さない。断りやすい一文を添える
```

## STEP 4：サンプリング実施の運用文面プロンプト

```
サンプリング協賛の実施にあたり、以下を作成してください。
1. 参加者への事前告知文（LINE配信用・協賛企業名を明記した「PR」表記つき）
2. 当日の配布時トーク（30秒）
3. 参加者アンケート（5問以内：認知・味/使用感・購入意向・自由記述など）
4. 参加者向けSNS投稿のお願い文（任意であること・PR表記の付け方を明記）
5. 実施後の企業向けレポートのテンプレート
```

## STEP 5：フォローアップ・継続提案プロンプト

```
- 未返信の企業への1週間後フォローアップ文（150字）
- 商談後のお礼メール
- 実施後レポート送付時に、継続協賛（年間パートナー：月{{MONTHLY_PRICE}}円）を提案する文
を作成してください。
```

## コンプライアンス
- 協賛企業の商品をSNS・LINE・ブログで紹介する際は **PR表記（広告である旨）** を必ず入れる（景品表示法のステマ規制）
- 参加者の個人情報を企業に提供する場合は **事前の同意** を取る（アンケートに同意欄）
- 食品サンプリングはアレルギー表示の掲示・事前告知を行う
