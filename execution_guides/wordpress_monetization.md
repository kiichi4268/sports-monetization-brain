## 2. PR表記（ステマ規制対応）— 必ず実施

2023年10月から、景品表示法に基づき **広告であることを隠した表示（ステルスマーケティング）が規制** されている。アフィリエイトを含む記事は、一般消費者が広告だと分かるように表示する。

### 2-1. 実装ルール
| 箇所 | 対応 |
|---|---|
| アフィリエイト・協賛を含む記事 | **記事タイトル直下〜冒頭**（ファーストビュー）に表記 |
| 表記文言例 | 「本記事にはプロモーション（広告）が含まれています」「PR」「広告」 |
| 文字の見やすさ | 背景色と同化させない・極端に小さくしない |
| 協賛企業から商品提供を受けた記事 | 「〇〇株式会社より商品提供を受けて作成しています」と具体的に |
| SNS・LINE・note での紹介 | 同様に「PR」「広告」等を明記 |
| サイト全体 | 「広告掲載について」ページで方針を明示（※ページ単位の表記の代わりにはならない） |

### 2-2. 実装方法
- テーマの機能（記事ごとのPR表記・カテゴリ単位の自動表示）があれば利用
- なければ再利用ブロック（パターン）で「PR表記ボックス」を作り、記事冒頭に挿入
- アフィリエイト記事チェックリストに「PR表記」を入れて公開前に必ず確認

### 2-3. 併せて注意する表現
- 「最安」「No.1」「業界初」等 → 客観的な根拠がある場合のみ、根拠と調査時点を併記
- 健康・痩身効果の断定（「飲むだけで痩せる」等）→ 使わない
- 価格・キャンペーン → 確認日を併記し、定期的に更新
- 体験していない商品の「使ってみた」表現 → 禁止

## 4. 収益化の仕組み

### 4-1. アフィリエイト配置の基本
| 位置 | 形式 | ポイント |
|---|---|---|
| 導入直後 | 結論ボックス（おすすめ1つ） | 結論を急ぐ読者向け |
| 本文中盤 | 比較表（3〜5商品） | 各行にボタン、選び方の基準を明記 |

| まとめ | おすすめ再提示 | 迷っている人の背中を押す |

### 4-2. 収益以外のコンバージョン
- **LINE登録**（イベント参加・note購入につながる）：全記事に設置
- **note誘導**：「サークル運営の裏側」カテゴリから
- **協賛企業の紹介記事**：PR表記・提供の明記を徹底

### 4-3. 広告（AdSense等）について
- PV 1万未満の段階では、アフィリエイト・LINE導線を優先（広告はクリックを奪う）
- 導入する場合は記事内の数を絞り、収益記事のCV導線を邪魔しない配置にする

## 7. note無料部分のブログ転載手順（第1弾note連携）

> 第1弾note（`execution_guides/note_launch_guide.md` §9-3）の無料エリアを、Sports Backstage の集客記事にする手順。
> **そのままコピーせず、ブログ用に作り直す**。同じ文章が2つのサイトにあると、検索エンジンがどちらを評価するか分散し、ブログ側が上位に出にくくなる。

### 7-1. 記事の設計

| 項目 | 内容 |
|---|---|
| メインKW | 社会人 スポーツサークル 一人参加 |
| サブKW | 初心者／運動不足／東京／気まずい／選び方 |
| タイトル案 | 「社会人がひとりでスポーツサークルに参加しても気まずくならない選び方【運営者が解説】」 |
| カテゴリ | はじめての社会人スポーツ（集客記事） |
| 文字数 | 3,000〜4,000字（noteの無料エリアを土台に、写真と会場の実例を足す） |
| ゴール | ① LINE登録（イベント予約） ② note購入 |

### 7-2. 転載の手順

1. **noteの無料エリアを土台にする**
   - 「3つの心理的ハードル」「4つのチェックリスト」はブログでも全文書く（ここが検索で読まれる部分）
   - 有料エリアの中身（挨拶テンプレ・チーム分けルールの詳細）は **ブログに書かない**。見出しだけ紹介し、noteへ案内する
2. **ブログ用に書き足す**（ブログにしかない内容にする）
   - 冒頭に「この記事で分かること」の箇条書き
   - 開催実績：9〜11月の会場・種目の例（`research/court_reservation_hack.md` §8）。会場の写真（施設の撮影ルールを確認）
   - 種目別の「初心者が最初にそろえるもの」（§8 のアフィリエイト配置へつなげる）
   - よくある質問（5問）：「何を持っていけばいい？」「ひとりは何割？」「飲み会は必須？」など
3. **見出し構成（例）**
   - H2 社会人がスポーツサークルに行けなくなる3つの理由
   - H2 ひとり参加で失敗しないサークル選び：4つのチェックリスト
   - H2 実際の開催例：都内9会場・4種目
   - H2 初参加の前にそろえるもの（→ §8）
   - H2 当日の挨拶と立ち回り（→ note紹介ボックス）
   - H2 よくある質問
   - H2 まとめ（LINE登録ボタン）
4. **noteとLINEへの導線を置く**
   - 「当日の挨拶と立ち回り」の見出しの下に **note紹介ボックス**：
     ```
     📘 当日そのまま使える「ひと言」テンプレと、気まずくならないチーム分けのルールはnoteにまとめました。
     先着10名 500円（以降980円 → 1,980円）／イベント500円OFFクーポン付き
     [ noteを読む ]
     ```
   - 記事末尾と本文中1か所に **LINE登録ボタン**（流入経路 `blog`）
5. **公開後**
   - noteの末尾（あとがき）からも、このブログ記事へリンクする（相互リンク）
   - noteの価格を変えたら、紹介ボックスの価格表記も同じ日に直す
   - Search Console に URL を送信し、2週間後に表示回数・クリックを確認

### 7-3. 注意点
- 自分のnoteの紹介は広告ではないが、記事内にアフィリエイトリンク（§8）を置く場合は **冒頭にPR表記** が必要（§2）
- 調査データ（クロス・マーケティング、2025年2月）を引用するときは、出典を明記してリンクする
- 参加者の写真は、掲載同意がある人だけを使う

## 8. 初心者向けスポーツグッズのアフィリエイト配置ガイド

> 会の4種目（バドミントン・バレーボール・卓球・フットサル）に合わせた、初心者向けグッズ記事の作り方と配置。
> 案件の提携・報酬は `research/affiliate_master_list.md` で管理する。価格は目安なので、記事には **確認日** を付けて販売ページの価格を書く。

### 8-1. 初心者が最初にそろえる順番（記事の軸）

体育館の多くは室内用シューズが必須で、ラケットやボールは会で貸し出せる。だから **「シューズ → ウェア → 保険 → 自分の道具」** の順で紹介すると、読者の実際の行動に合う。

| 優先度 | アイテム | 必要になるタイミング | 予算の目安 | 主な収益案件 |
|---|---|---|---|---|
| 1 | 室内用シューズ（体育館シューズ） | 初参加の前 | 5,000〜10,000円 | スポーツ用品EC、Amazon・楽天（もしも） |
| 2 | ウェア（吸汗速乾Tシャツ・ハーフパンツ） | 初参加の前 | 2,000〜5,000円 | スポーツブランド公式、Amazon・楽天 |
| 3 | スポーツ保険（個人向け） | 定期的に参加し始めたら | 年額数千円程度〜 | 保険系ASP案件 |
| 4 | 自分のラケット（バド・卓球） | 2〜3回参加して続けたくなったら | 3,000〜10,000円 | スポーツ用品EC、専門店 |
| 5 | サポーター・ケア用品 | ブランクが長い人・30代以降 | 1,000〜3,000円 | Amazon・楽天 |
| 6 | プロテイン・ドリンク | 習慣化してから | 2,000〜5,000円 | プロテイン案件 |

### 8-2. 種目別の選び方ポイント（記事にそのまま使う）

| 種目 | アイテム | 初心者向けの選び方 |
|---|---|---|
| 🏸 バドミントン | ラケット | 重さは軽めの **4U〜5U** から。バランスはイーブン〜ヘッドライトが振りやすい。ガット張り上げ済みの完成品を選ぶ |
| 🏸 バドミントン | シューズ | バドミントン用またはインドア用。ランニングシューズは横の動きで滑りやすい |
| 🏐 バレーボール | シューズ・サポーター | バレーボール用またはインドア用シューズ。膝をつく動きが多いので膝サポーターがあると安心 |
| 🏓 卓球 | ラケット | ラバーが貼ってある **完成品ラケット（シェークハンド）** から。自分で組み合わせるのは慣れてから |
| ⚽ フットサル | シューズ | 会場に合わせる：体育館ならインドア用、人工芝ならターフ用。スパイクは使えない会場が多い |
| 共通 | ウェア | 綿より吸汗速乾素材。汗冷えしないように着替えを1枚 |
| 共通 | 保険 | 会の団体保険の範囲（当日のケガのみなど）を確認し、足りない部分を個人で補う |

### 8-3. 記事の型と配置

**記事例**：「【初心者向け】社会人がバドミントンを始めるときにそろえるもの｜最初はシューズだけでOK」

| 位置 | 置くもの | 形式 | 読者の気持ち |
|---|---|---|---|
| タイトル直下 | **PR表記** | テキスト | — |
| 導入の直後 | 結論ボックス：「最初に買うのはシューズ1足だけ」＋おすすめ1つ | ボックス＋ボタン | 何を買えばいいか早く知りたい |
| 「シューズの選び方」の後 | シューズ比較表（3〜5足） | 表＋ボタン（価格を見る） | 比べて選びたい |
| 「ウェア」の後 | テキストリンク2〜3本 | テキストリンク | ついでにそろえたい |
| 「ケガと保険」の後 | 保険の案内（会の団体保険との違いを説明してから） | ボックス＋ボタン | ケガが不安 |
| 「ラケットは貸出あり」の後 | 「続けたくなったら」のラケット比較 | 表＋ボタン | 今は買わなくていいと分かって安心 |
| まとめ | 結論の再掲＋LINE登録ボタン（イベント案内）＋note紹介 | ボタン | まず1回参加してみたい |

**配置のルール**
- 「最初は買わなくていいもの」もはっきり書く（ラケットは貸出、など）。押し売りしないほうが信頼されてクリックも増える
- 比較表の商品は、実際に使ったものを優先し、使っていないものは「公式情報によると」と書く
- 保険は「必ず入るべき」と断定しない。会の団体保険で何がカバーされるかを先に書き、個人保険は「さらに備えたい人向け」として紹介する
- ボタンの文言は「公式サイトで詳細を見る」「Amazonで価格を見る」など、押した後に何が起きるか分かる表現にする
- 価格・セール情報には【確認日：YYYY-MM-DD】を付ける

### 8-4. 最初に書く5記事（グッズ系）

| 1 | 社会人がバドミントンを始めるときにそろえるもの｜最初はシューズだけでOK | バドミントン 初心者 必要なもの | シューズ・ウェア・ラケット |
| 2 | 初心者向けバドミントンラケットの選び方とおすすめ【4U・5Uの違い】 | バドミントン ラケット 初心者 | ラケット |
| 3 | 体育館シューズの選び方｜バド・バレー・卓球・フットサル別 | 体育館シューズ おすすめ 大人 | シューズ |
