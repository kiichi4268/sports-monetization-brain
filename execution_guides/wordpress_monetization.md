### 1-4. プラグイン（最小限）
| 目的 | 種類 | 備考 |

| セキュリティ | ログイン保護・不正アクセス対策 | |

## 2. PR表記（ステマ規制対応）— 必ず実施

2023年10月から、景品表示法に基づき **広告であることを隠した表示（ステルスマーケティング）が規制** されている。アフィリエイトを含む記事は、一般消費者が広告だと分かるように表示する。

### 2-1. 実装ルール
| 箇所 | 対応 |
|---|---|
| アフィリエイト・協賛を含む記事 | **記事タイトル直下〜冒頭**（ファーストビュー）に表記 |
| 表記文言例 | 「本記事にはプロモーション（広告）が含まれています」「PR」「広告」 |
| 文字の見やすさ | 背景色と同化させない・極端に小さくしない |
| 協賛企業から商品提供を受けた記事 | 「〇〇株式会社より商品提供を受けて作成しています」と具体的に |
| SNS・LINE・note での紹介 | 同様に「PR」「広告」等を明記 |
| サイト全体 | 「広告掲載について」ページで方針を明示（※ページ単位の表記の代わりにはならない） |

### 2-2. 実装方法
- テーマの機能（記事ごとのPR表記・カテゴリ単位の自動表示）があれば利用
- なければ再利用ブロック（パターン）で「PR表記ボックス」を作り、記事冒頭に挿入
- アフィリエイト記事チェックリストに「PR表記」を入れて公開前に必ず確認

### 2-3. 併せて注意する表現
- 「最安」「No.1」「業界初」等 → 客観的な根拠がある場合のみ、根拠と調査時点を併記
- 健康・痩身効果の断定（「飲むだけで痩せる」等）→ 使わない
- 価格・キャンペーン → 確認日を併記し、定期的に更新
- 体験していない商品の「使ってみた」表現 → 禁止

## 3. 記事作成フロー（1記事 約2時間）

```
① KW選定(10分) → ② 構成(20分/AI) → ③ 一次情報の準備(20分/写真・数値)
→ ④ 執筆(40分/AI下書き＋人が加筆) → ⑤ アフィ配置・PR表記(10分)
→ ⑥ 装飾・画像・内部リンク(15分) → ⑦ 公開前チェック(5分) → ⑧ SNS/LINEで告知
```

### 記事タイプと比率（最初の30記事）

| タイプ | 本数 | 目的 | 例 |
|---|---|---|---|
| 集客記事（Know/Do） | 12 | PV・LINE登録 | 「社会人 バドミントン 始め方 東京」 |
| ローカル施設ガイド | 6 | ローカルSEO | 「〇〇区 体育館 個人開放 ガイド」 |
| 収益記事（比較・おすすめ） | 8 | アフィリエイト | 「初心者向けラケット おすすめ」「大人のテニススクール比較」 |
| イベントレポート・運営の裏側 | 4 | E-E-A-T・note導線 | 「初心者バド会 第10回レポート」「サークル収支公開」 |

### 公開前チェックリスト
- [ ] タイトルにメインKW（左寄せ）
- [ ] メタディスクリプション（120字前後）
- [ ] 冒頭にPR表記（アフィ記事のみ）
- [ ] 一次情報（自分で撮った写真・数値・体験）が2箇所以上
- [ ] 見出し構成が検索意図に答えている
- [ ] 内部リンク3本以上（集客記事 → 収益記事）
- [ ] LINE登録ボタン（記事末尾＋本文中1箇所）
- [ ] 画像に代替テキスト（alt）、ファイルは圧縮済み
- [ ] 写真に写る人物の掲載同意（アンケートの同意タグで確認）
- [ ] スマホでの表示確認

## 4. 収益化の仕組み

### 4-1. アフィリエイト配置の基本
| 位置 | 形式 | ポイント |
|---|---|---|
| 導入直後 | 結論ボックス（おすすめ1つ） | 結論を急ぐ読者向け |
| 本文中盤 | 比較表（3〜5商品） | 各行にボタン、選び方の基準を明記 |
| 各商品の解説末尾 | テキストリンク＋ボタン | ボタン文言は「公式サイトで詳細を見る」等、行動が分かる表現 |
| まとめ | おすすめ再提示 | 迷っている人の背中を押す |

### 4-2. 収益以外のコンバージョン
- **LINE登録**（イベント参加・note購入につながる）：全記事に設置
- **note誘導**：「サークル運営の裏側」カテゴリから
- **協賛企業の紹介記事**：PR表記・提供の明記を徹底

### 4-3. 広告（AdSense等）について
- PV 1万未満の段階では、アフィリエイト・LINE導線を優先（広告はクリックを奪う）
- 導入する場合は記事内の数を絞り、収益記事のCV導線を邪魔しない配置にする

```
          [まとめ記事] 社会人が東京でスポーツを始める完全ガイド
             ├── 種目別の始め方（バド/フットサル/テニス…）
             │      └── 【収益】初心者向けギアおすすめ
             ├── 都内の施設・コートガイド（区別）
             │      └── 【note】コート確保の全手順
             ├── カラダづくり
             │      └── 【収益】プロテイン比較／パーソナルジム比較
             └── ケガと保険
                    └── 【収益】スポーツ保険の選び方
```

- まとめ記事（ピラー）から各記事へ、各記事からピラーと収益記事へ相互リンク
