# LINE自動化 設定手順書：離脱ゼロ導線 ＆ デジタル参加証の完全自動発行

> **ゴール**：友だち追加 → 予約 → 参加証発行 → リマインド → 参加後アンケート → 次回予約 までを **無料ツールで全自動化** する。
> **使用ツール**：LINE公式アカウント（無料プラン）＋ エルメ（L Message）フリープラン
> **注意**：両サービスとも画面名称・無料枠・機能は変更されることがある。設定時は **各サービスの最新ヘルプ** を確認し、このファイルを更新すること。
> **SNS自動投稿システムとの関係**：SNS自動投稿は別リポジトリで管理。本手順はLINE側の設定のみを扱う。

---

## 0. 全体フロー

```
[SNS/ブログ]
     │ プロフィールのリンク（流入元ごとにQR/URLを分ける）
     ▼
① 友だち追加 ──▶ 自動あいさつ（特典＋次回イベント案内）＋ 流入元タグ付与
     │
     ▼
② リッチメニュー「イベント予約」 ──▶ 予約フォーム（3項目以内）
     │
     ▼
③ 予約完了 ──▶ タグ「予約_YYYYMMDD」付与 ＋ デジタル参加証を自動送信
     │
     ▼
④ 前日 20:00 リマインド ／ 当日 2時間前 リマインド（アクセス・持ち物）
     │
     ▼
⑤ 当日受付：参加証を見せる → スタッフがフォームで「来場」チェック
     │
     ▼
⑥ 終了後 自動：お礼＋写真共有＋アンケート（回答特典つき）
     │
     ▼
⑦ アンケート回答 ──▶ 興味タグ付与 ──▶ 次回予約 / note / ブログ記事へセグメント配信
```

## 1. 事前準備（30分）

- [ ] LINE公式アカウントを作成（イベント名・プロフィール画像・背景画像・あいさつ文）
- [ ] プロフィールに「初心者・一人参加歓迎」「勧誘禁止」を記載
- [ ] **プライバシーポリシー** を用意（ブログの固定ページでOK）：取得する情報・利用目的・第三者提供の有無
- [ ] エルメ（L Message）に登録し、LINE公式アカウントと連携
- [ ] LINE公式アカウント側の応答設定を、エルメ連携の推奨設定に合わせる（チャット/Webhook の設定）

> 無料プランは **月の配信通数に上限** がある。友だち数×配信回数が上限を超えそうになったら、セグメント配信で通数を節約するか、有料プランを検討する。

## 2. 友だち追加時の設定（離脱防止の最重要ポイント）

### 2-1. 流入経路の分析設定
- エルメの **流入経路（QRコード/URL）** を流入元ごとに作成：`instagram` / `x` / `tiktok` / `blog` / `event_qr` / `referral`
- 各経路で自動的に **タグ「流入_〇〇」** を付与 → どのSNSが友だちを連れてくるか計測

### 2-2. あいさつメッセージ（自動送信）

```
{名前}さん、友だち追加ありがとうございます！🏸
初心者・一人参加の方が8割の「〇〇スポーツ会」です。

🎁 追加特典：「都内で運動を始める人のための体育館マップ」
　→ 下のボタンから受け取れます

📅 次回のイベント
　〇月〇日(土) 13:00〜 渋谷区（残り◯席）
　→ 下のメニュー「イベント予約」から3タップで予約できます

不安なことは、このトークにそのままメッセージしてください😊
```

- ボタン（カルーセル or ボタンテンプレート）：「特典を受け取る」「次回イベントを見る」「よくある質問」
- **離脱防止のコツ**：
  1. 追加直後に「次の行動」を1つだけ提示する（予約 or 特典）
  2. 特典受け取りボタンを押した人にタグ `特典受取` を付与 → 反応した人だけに追撃
  3. 24時間後に未予約者へステップ配信（後述）

### 2-3. ステップ配信（未予約者フォロー）

| タイミング | 条件 | 内容 |
|---|---|---|
| 追加後 1日 | タグ「予約_*」なし | 「よくある不安トップ3」とその答え（一人参加・レベル・持ち物） |
| 追加後 3日 | 同上 | 前回イベントの写真＋参加者の声 |
| 追加後 7日 | 同上 | 初回限定割引 or 初心者限定回の案内 |
| 予約した時点 | タグ「予約_*」付与 | ステップ配信を **停止** |

## 3. リッチメニュー

| ボタン | アクション | 補足 |
|---|---|---|
| 📅 イベント予約 | 予約フォーム（またはエルメの予約機能）を開く | 最も大きく配置 |
| 🎫 マイ参加証 | 直近の参加証を再送信（キーワード応答 or アクション） | 当日「参加証どこ？」問題を解消 |
| ❓ はじめての方へ | FAQ・持ち物・アクセス | |
| 📖 ノウハウ集 | ブログ・noteへのリンク | 収益導線 |
| 💬 お問い合わせ | チャットへ | |

> 参加回数タグで **リッチメニューを出し分け**（新規向け／常連向け）できると、常連にはnote・上位イベントを前面に出せる。

## 4. 予約フォーム（3項目以内）

| 項目 | 形式 | 必須 | 目的 |
|---|---|---|---|
| 参加日 | 選択（開催日のプルダウン） | ○ | 予約枠 |
| レベル | 選択（未経験/ブランクあり/経験者） | ○ | コート分け |
| 不安なこと・質問 | 自由記述 | 任意 | 事前フォロー＆コンテンツネタ |

- **名前はLINE表示名で代替**し、入力項目を減らす（入力が増えるほど離脱する）
- フォーム送信時のアクション：
  1. タグ付与：`予約_YYYYMMDD`、`レベル_〇〇`
  2. 定員管理：回答数が定員に達したら「満員」表示＋キャンセル待ちフォームへ誘導
  3. 参加証メッセージの送信（次章）
  4. 管理者への通知

## 5. デジタル参加証の自動発行

### 5-1. 参加証の作り方（無料）
1. Canva等で参加証のテンプレ画像を作成（イベント名・日付・会場・「この画面を受付で提示」）
2. 開催回ごとに画像を作成（名前は入れない＝1回につき1枚で済む）
3. エルメの **フレックスメッセージ／カードタイプメッセージ** で以下を組み合わせる：
   - 参加証画像
   - 動的テキスト：`{LINE表示名}` 様／受付番号（友だちID末尾など、エルメで使える変数を利用）
   - ボタン：「会場の地図」「持ち物を確認」「キャンセルする」

### 5-2. 参加証メッセージ文例

```
🎫 参加証｜〇〇スポーツ会
━━━━━━━━━━━━
{名前} 様
📅 〇月〇日(土) 13:00〜15:00（12:45受付開始）
📍 〇〇区立〇〇体育館 第1体育室
💰 参加費 1,500円（当日現金 or 事前決済済み）
━━━━━━━━━━━━
受付でこの画面を見せてください。
※キャンセルは前日20時までに下のボタンから
```

### 5-3. 当日の受付
- スタッフは参加証画面を目視確認 → 管理画面 or スタッフ用フォームで **タグ「来場_YYYYMMDD」** を付与
- 来場タグをトリガーに、参加回数カウント（`参加_1回` → `参加_3回以上`）を更新

### 5-4. キャンセル処理（自動繰上げ）
- 「キャンセルする」ボタン → タグ `予約_YYYYMMDD` を外し `キャンセル_YYYYMMDD` を付与
- キャンセル待ちタグを持つ人へ「空きが出ました」を自動配信（先着）

## 6. リマインド配信

| タイミング | 対象 | 内容 |
|---|---|---|
| 前日 20:00 | `予約_YYYYMMDD` | 持ち物・集合時間・アクセス・キャンセル期限 |
| 当日 2時間前 | 同上 | 「本日お待ちしています」＋参加証の再表示ボタン |
| 当日 終了30分後 | `来場_YYYYMMDD` | お礼・写真アルバムURL・アンケート |

> 予約日時を起点にした **日時指定のリマインド** はエルメの予約/リマインダー機能で設定可能か確認。難しい場合は、開催日ごとにタグ絞り込みの予約配信を手動で1回セットする（1回5分）。

## 7. 参加後アンケート → 収益導線

| 質問 | 形式 | 回答時アクション |
|---|---|---|
| 満足度（1〜5） | 選択 | 4以上 → 口コミ・紹介のお願い配信 |
| 次回も参加したいか | 選択 | 「はい」→ 次回予約リンクを即送信 |
| 興味のあるテーマ（複数可） | 選択：上達したい／体づくり／サークル運営／ギア | タグ `興味_上達` `興味_健康` `興味_運営` `興味_ギア` |
| 困っていること | 自由記述 | note・ブログのネタ帳に転記 |
| 写真のSNS掲載可否 | 選択 | 掲載可タグ（同意の記録） |

- 回答特典：次回100円引き or 入門noteの割引クーポン
- 興味タグ別の配信例：
  - `興味_運営` → 有料note「サークル運営の全手順」
  - `興味_健康` → ブログ「社会人向けプロテインの選び方」
  - `興味_上達` → スクール比較記事・練習会案内

## 10. note購入者・イベント参加者向けテンプレ（第1弾note連携）

> 第1弾note（`execution_guides/note_launch_guide.md` §9）の購入者と、イベント参加者に送るメッセージ。
> クーポンは **LINE公式アカウントのクーポン機能** で作成し、エルメのキーワード応答・アクションで配布する（機能名・設定画面は最新のヘルプで確認）。

### 10-1. 仕組み

```
[note購入者]  有料エリアの友だち追加URL（流入経路 note）
      │
      ▼
  友だち追加 → タグ「流入_note」 → note購入者向けあいさつ（10-2）
      │
      ▼
  合言葉を送信 → キーワード応答 → タグ「note購入者」＋ 500円OFFクーポン（10-4）
      │
      ▼
  イベント予約 → 参加証 → 当日受付でクーポン画面を提示 → タグ「クーポン利用済」

[イベント参加者]  来場タグ「来場_YYYYMMDD」
      │
      ▼
  参加後のあいさつ（10-3）→ アンケート → 次回予約／note案内
```

### 10-2. note購入者向け あいさつメッセージ（友だち追加時：流入経路 note）

```
{名前}さん、noteを読んでくださってありがとうございます！
運営の【名前】です😊

noteでお伝えした「500円OFFクーポン」は、
このトークに 合言葉 を送ると自動で届きます。

合言葉：【例：ひとりでも大丈夫】

クーポンは、初めてイベントに参加するときに使えます。
次回のイベントは下のメニュー「イベント予約」から見られます📅

当日、受付で「noteを読みました」と言ってもらえたら、
運営からも声をかけますね。
```

**合言葉への自動返信（クーポン配布）**
```
ありがとうございます！クーポンをお送りします🎁

━━━━━━━━━━━━
イベント参加 500円OFFクーポン
━━━━━━━━━━━━
▶【クーポンURL／クーポンカード】

・初参加のイベントで、参加費から500円OFF
・受付でこの画面を見せてください
・1人1回まで／ほかの割引との併用不可
・有効期限：【受け取りから60日など】

予約はメニュー「イベント予約」から3タップです。
```

**設定**
- エルメの流入経路「note」を作成し、そのURLを note の有料エリアに貼る（友だち追加時にタグ `流入_note`）
- キーワード応答：合言葉と完全一致 → 上のクーポン配布メッセージ＋タグ `note購入者` を付与
- 合言葉は有料エリアにだけ書く。SNSで広まった場合に備え、**第2段階（980円）・通常価格（1,980円）に上がるタイミングで合言葉を変える**（古い合言葉には「合言葉が変わりました。最新のnoteをご確認ください」と返す）
- 同じ人が何度もクーポンを受け取らないよう、`note購入者` タグがある人には「クーポンはお送り済みです」と返す（エルメの条件分岐で設定）

### 10-3. イベント参加者向け あいさつメッセージ（参加後：来場タグ付与時）

**初参加の人（タグ `参加_1回`）**
```
{名前}さん、今日はご参加ありがとうございました！🏸🏐🏓⚽
久しぶりの運動、おつかれさまでした。

ひとりで参加するのは、きっと勇気がいったと思います。
来てくれて本当にうれしかったです。

📷 今日の写真はこちら（掲載OKの方のみ）
【アルバムURL】

📝 1分アンケートにご協力ください
【アンケートURL】
回答してくれた方には、次回使える500円OFFクーポンをお送りします🎁

次回のイベントは、メニュー「イベント予約」から見られます。
またお会いできるのを楽しみにしています！
```

**2回目以降の人（`参加_1回` 以外の来場者）**
```
{名前}さん、今日もありがとうございました！
いつも来てくださって、本当に助かっています😊

今日、初参加の方が【◯】人いました。
次回も、初めての方に声をかけてもらえるとうれしいです。

📝 アンケート：【アンケートURL】
📅 次回の先行予約：【予約URL】（常連の方に先にお知らせしています）
```

> 初参加の人へのお礼を最優先で届けるため、来場タグが付いたら **終了30分後** に自動送信する（§6 のリマインド配信と同じ枠で設定）。

### 10-5. クーポン設定のチェックリスト
- [ ] クーポンの種類ごとに **割引額・対象・有効期限・1人1回** を設定した
- [ ] 文面の条件とクーポン側の設定が一致している
- [ ] 当日の受付で、スタッフがクーポン画面を確認 → タグ `クーポン利用済` を付ける手順を決めた
- [ ] クーポン使用時の参加費（1,500円 → 1,000円）を、イベントの収支計算（`strategy/revenue_model.md`）に反映した
- [ ] 同じ人が①〜④を重ねて使えないよう、併用不可を明記した
