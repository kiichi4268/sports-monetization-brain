# 有料note 公開・集客・販売 完全ガイド

> **ゴール**：有料noteを「書いて終わり」にせず、**SNS・LINE・ブログから継続的に売れる商品** にする。
> **目標**：第1弾 初週10部／初月30部 → 3商品ラインナップで月純売上9万円（`strategy/revenue_model.md`）
> **制作**：`prompts/02_note_creator.md`
> ※ note の手数料・機能（メンバーシップ、マガジン、クーポン等）は変更されることがあるため、公開前に公式ヘルプで最新情報を確認する。

---

## 1. 公開前の準備（アカウント設計）

- [ ] プロフィール：顔 or ロゴ／「都内で社会人スポーツ会を運営｜累計◯回・◯人」など実績を数字で
- [ ] プロフィールのリンク：LINE公式（流入経路 `note` で計測）とブログ
- [ ] 無料記事を **3〜5本** 先に公開（信頼の土台＋有料記事への内部導線）
  - 例：「サークルを始めて3ヶ月の収支を全部公開」「初心者バド会で起きた5つの失敗」
- [ ] 売上の受取設定（振込口座など）を完了
- [ ] 特定商取引法に基づく表記の要否・表示方法を確認（note のヘルプに従う）

## 2. 商品ラインナップ設計

| 段階 | 商品例 | 価格 | 役割 |
|---|---|---|---|
| 無料 | 収支公開・失敗談・イベントレポート | 0円 | 認知・信頼 |
| 入門 | 都内でコートを確実に押さえる方法 | 1,000円 | 初回購入のハードルを下げる |
| 実践 | 社会人スポーツサークルの作り方【集客編】 | 1,980円 | 主力商品 |
| 完全版 | サークル運営で月3万円の利益を出す全手順＋テンプレ一式 | 3,980円 | 利益の柱 |
| まとめ | 有料マガジン（入門＋実践＋完全版） | 単品合計より割安 | 客単価アップ |

> **アップセル導線**：入門noteの末尾で実践・完全版を紹介。購入者限定クーポンで「上位版を割引」。

## 3. 記事ページの作り込み

### 3-1. タイトル・見出し画像
- タイトル：32文字前後。「数字」「対象者」「ベネフィット」を2つ以上
  - 例：「【当選率12%→68%】都内の区立体育館でコートを毎月確保する全手順」
- 見出し画像：タイトルの要点を大きく1行、実績数字を入れる（Canva 1280×670 目安）

### 3-2. 無料部分の型（有料ラインまで）
1. フック：読者の痛み（3行）
2. 実績：数字で信頼性
3. 得られること：箇条書き5〜7個
4. 向いている人／向いていない人
5. 目次（有料部分の見出しをすべて見せる）
6. 購入者の声（2本目以降）
7. 有料ライン直前の“引き”

### 3-3. 有料部分
- 一次情報（実数・スクショ・テンプレ）を各章に必ず入れる
- テンプレはコピペできる形（表・コードブロック）か、ダウンロードリンク
- 末尾に「購入者限定：LINEで質問できます」等の特典（運用負荷と相談して）

## 4. 価格・販売設定

| 設定 | 推奨 |
|---|---|
| 価格 | 1,000／1,980／2,980／3,980円から選ぶ |
| 公開直後の価格 | **「初週限定価格」**（例：1,980円 → 公開1週間は1,480円）で初速を作る（期限は正確に告知し、守る） |
| 部数限定 | 「先着◯部は◯円」も初速に効果的（限定数は守る） |
| マガジン | 2本以上揃ったら有料マガジン化 |
| クーポン | イベント参加者・LINE友だち向けに配布（機能の有無を確認） |

> 「今だけ」「限定」の表示は事実どおりに運用する（期限後に同じ価格で再販し続ける等は有利誤認のリスク）。

## 6. 集客チャネル別の告知テンプレ

### X（140字）
```
【3ヶ月連続で抽選に外れた僕が、当選率68%になるまで】
都内の区立体育館でコートを毎月押さえる方法を、申込記録の実データつきで全部まとめました。
✅ 登録できる区の洗い出し方
✅ 倍率が下がる"狙い目枠"
✅ 外れた時の代替プラン
初週限定価格です👇
```

### Instagram（カルーセル10枚構成）
1. 表紙（タイトル＋実績）／2. 悩みの共感／3〜7. ノウハウの一部（無料で役立つレベル）／8. noteで分かること／9. 購入者の声／10. 「プロフィールのリンクから」

### LINE（300字以内）
```
{名前}さん、こんにちは！
アンケートで「サークルを自分でも作りたい」と回答いただいた方に先行でお知らせです。

これまでの◯回の運営で分かった「コート確保・集客・収支」のすべてをnoteにまとめました📘

▶ LINE限定：〇月〇日 23:59まで 1,480円（通常1,980円）
[ noteを読む ]

ご質問はこのトークへどうぞ😊
```

### ブログ
- 関連記事の文中・末尾に **紹介ボックス**（タイトル・3行要約・価格・ボタン）を設置
- 「サークル運営の裏側」カテゴリの記事からnoteへ内部導線

## 7. 販売後の運用

- [ ] 購入者へのお礼（noteのメッセージ機能・LINE等、使える範囲で）とレビュー依頼
- [ ] レビュー・感想をLP（無料部分）に追記（本人の許可を得て）
- [ ] 毎月、一次情報を **アップデート**（「〇月版に更新しました」は再告知のきっかけになる）
- [ ] 質問が多い内容は追記 or 次のnoteのテーマに

## 8. KPIと改善の打ち手

| 指標 | 目安 | 低いときの打ち手 |
|---|---|---|
| 記事ビュー数 | 月2,500〜3,000 | 告知回数を増やす／ブログからの導線を増やす／無料記事を追加 |
| 購入率（ビュー→購入） | 2%前後 | 無料部分の改善：フック・実績・目次の具体性・購入者の声 |
| LINE配信からの購入率 | 5〜10% | セグメントの精度を上げる（興味タグ）／期限つき特典 |
| 返金・低評価 | ほぼゼロ | 「向かない人」の明記、期待値調整 |
| スキ数 | 参考指標 | タイトル・見出し画像のテスト |
