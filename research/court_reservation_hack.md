# 区立体育館・コート確保の攻略ノウハウ

> イベント事業の最大のボトルネックは **「会場（コート）を安定して確保できるか」**。
> このファイルは、都内の区立体育館の抽選・空き枠・個人開放を攻略するための知識と記録を蓄積する。

> ⚠️ **大前提：各施設・各区の利用規約を必ず守ること。**
> 名義貸し、架空団体での複数登録、他人のIDの借用、転売目的の予約、営利利用の禁止規定への違反などは、利用停止や登録抹消の対象になり得る。
> 特に「営利目的の利用」の扱いは区ごとに異なるため、**参加費を徴収するイベントで使ってよいか** を事前に施設へ確認する。

## 1. 基礎知識

### 施設予約の仕組み（一般的な流れ）

```
① 利用者（団体）登録 → ② 抽選申込（翌月 or 数ヶ月先の枠） → ③ 抽選結果確認
→ ④ 当選枠の確定手続き（期限あり） → ⑤ 空き枠の先着予約（抽選後に開放） → ⑥ 利用・支払い
```

| 用語 | 意味 | 攻略上のポイント |
|---|---|---|
| 団体登録 | 区内在住・在勤者を含む一定人数での登録が必要なことが多い | 登録要件（人数・在住在勤割合・代表者要件）を確認 |
| 抽選 | 人気枠（土日・夜間）は抽選 | 倍率の低い枠を狙う（§3） |
| 当選確定 | 当選後に期限内の確定手続きが必要 | **確定忘れ＝失効**。リマインド必須 |
| 空き枠先着 | 抽選後の未確定・キャンセル枠を先着で開放 | 開放日時にアクセスするのが最重要 |
| 個人開放（個人利用日） | 予約不要で1人数百円程度で使える開放日 | 少人数練習・下見・小規模会に活用 |
| 区民／区外料金 | 区外者は料金が高い・予約不可の場合あり | 自分が登録できる区を洗い出す |

## 3. 抽選倍率の攻略

### 倍率記録シート（毎月記入 → 3ヶ月で傾向が見える）

| 年月 | 施設 | 曜日 | 時間帯 | 申込数（公開されていれば） | 枠数 | 倍率 | 結果 | メモ |
|---|---|---|---|---|---|---|---|---|
| YYYY-MM | | 土 | 午前 | | | | 当選/落選 | |

> 倍率が公開されていない場合は「自分の当選率（当選数 ÷ 申込数）」を記録する。

### 倍率が下がりやすい枠（一般的な傾向・要検証）

| 狙い目 | 理由 | 想定する活用 |
|---|---|---|
| 日曜の夕方〜夜 | 翌日が仕事で敬遠されがち | 社会人向けの「日曜リフレッシュ会」 |
| 土日の朝一番（9時前後） | 早起きが敬遠される | 「朝活スポーツ」としてむしろ訴求に変える |
| 平日夜の遅い枠 | 終了時間が遅い | 仕事帰りの「平日夜会」 |
| 祝日・連休中日 | 旅行・帰省で申込減 | 連休限定イベント |
| 年度替わり・年末年始前後 | 団体の再登録や繁忙期 | — |
| 駅から遠い施設 | アクセスで敬遠 | 「駅からの道順動画」で参加ハードルを下げる |
| 新設・改修直後の施設 | 認知が低い | 公式サイトの「お知らせ」をウォッチ |

### 申込テクニック（規約の範囲内で）
1. **第一〜第三希望を戦略的に配置**：第一希望＝本命、第二・第三＝倍率の低い枠で「保険」をかける
2. **複数区での並行申込**：正規に登録できる区すべてで申し込み、当選分母を増やす
3. **面の単位を変える**：全面が取れなければ半面・1/3面で申し込む（バドミントンは少面でも成立）
4. **時間を細切れにしない**：2時間未満は準備・片付けで実質時間が短く、満足度が下がる
5. **当選後の確定はその日のうちに**：確定忘れを防ぐため、結果発表日にカレンダーリマインドを設定

## 4. 空き枠・キャンセル枠の確保

- 抽選後の空き枠開放の **日時** を施設ごとにカレンダー登録（開放直後が勝負）
- 開催日の **1週間前〜前日** はキャンセルが出やすい → 予約システムを定期的に確認
- 空き枠が取れた場合に備え、**「急遽開催」用の募集文テンプレ** と LINE配信テンプレを用意しておく
- ⚠️ 自動アクセスツール（ボット）による予約は、多くの予約システムで禁止または不正アクセスと見なされ得るため **使用しない**

## 5. 個人開放日の活用

| 活用方法 | 内容 |
|---|---|
| 少人数練習会 | 4〜8人の「レベルアップ練習会」として告知（参加費は施設の個人利用料＋運営費程度） |
| 下見 | 新施設の設備・更衣室・アクセスを確認し、ブログ記事化 |
| コンテンツ撮影 | 練習メニューの動画撮影（※施設の撮影ルールと他利用者の映り込みに注意） |
| ブログネタ | 「〇〇区 個人開放 バドミントン 完全ガイド」はSEO需要あり |

> 個人開放日は「団体の占有」ではないため、**他の利用者の迷惑にならない範囲で**。営利の募集が禁止されている施設では有料イベントとして告知しない。

## 6. 代替手段（抽選に外れたとき）

| 手段 | コスト | メリット | デメリット |
|---|---|---|---|
| 民間スポーツ施設・レンタルコート | 高 | 予約が確実・先着 | 利益率が下がる → 参加費を調整 |
| 学校の体育館開放（学校施設開放事業） | 低 | 安い | 登録要件が厳しい・時間帯が限られる |
| 他団体との共催 | 中 | 相手のコートを活用 | 収益分配の調整が必要 |
| 屋外（公園のテニスコート・広場） | 低 | 種目を変えて開催 | 天候リスク |

### 8-5. 読み取れること（次の抽選申込に使う）

1. **祝日・休日が全体の3分の1（27回中9回）**。9月の連休（9/21〜23）だけで5回。祝日は §3 の「狙い目枠」どおり確保できている → 12月以降も祝日枠を優先して申し込む
2. **会場ごとに種目と時間帯がほぼ固定**されている（中野＝土曜昼バレー、大久保スポーツプラザ＝祝日昼卓球、まもりやまテラス＝木曜夜・土曜午後バド）。参加者が覚えやすいので、毎月同じ枠で定期開催にする
3. **平日開催は4回だけで、そのうち3回がまもりやまテラスの木曜夜**。平日夜の参加者を増やすなら、まもりやまテラスの木曜枠を毎月確保する
4. **同日2会場が5日ある**。運営者が2人以上いないと回らないため、各回の担当者を事前に決める
5. **バドミントンは4会場に分散している**（地域交流センター代々木の杜・まもりやまテラス・目黒区民センター・渋谷区本町）。1会場が抽選に外れても他で埋められる状態で、§6 の代替手段が機能している
6. 各会場の料金・抽選日程・空き枠開放日は §2 の施設リストに記入し、12月以降の申込に使う

### 8-6. 記録の追加ルール
- 新しい月は §8-3 に行を追加し、§8-1 の回数と §8-4 の集計を更新する
- 抽選に外れた枠も §3 の「倍率記録シート」に残す（当選率が分かるように）
- 開催後は参加人数・利益を `strategy/revenue_model.md` の実績記録欄へ
