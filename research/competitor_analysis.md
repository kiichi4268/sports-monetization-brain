# 競合分析：都内スポーツサークル・イベント

> 目的：都内の競合サークル／イベント主催者の **単価・集客手法・強み弱み** を構造化し、自分のポジションと価格を決める。
> 分析には `prompts/01_research_analyst.md` を使用。結果はこのファイルに蓄積する。

---

## 1. 調査の進め方

1. **リストアップ**（最低10件、理想20件）
   - 検索キーワード例：「東京 社会人 バドミントン サークル 初心者」「渋谷 フットサル 個サル」「都内 一人参加 スポーツ イベント」
   - 探す場所：Google検索／Googleマップ／Instagram・Xのハッシュタグ／イベント募集プラットフォーム（スポーツ系募集サイト、つながり系イベントサイト、MeetUp系サービス）／ジモティー等の掲示板
2. **基本情報を比較表に記入**（下記 §2）
3. **集客導線を分解**（下記 §3）
4. **口コミ・レビューから不満を抽出**（下記 §4）＝自分の差別化ポイント
5. **ポジショニングマップに配置**（下記 §5）

> ⚠️ 調査は公開情報の範囲で行う。体験参加する場合は運営ルールを守り、内部情報の持ち出しや引き抜き行為はしない。

## 3. 集客手法の分解シート

| 競合名 | 認知チャネル | 投稿頻度 | 主なコンテンツ | 予約導線 | リピート施策 | 収益の柱（推定） |
|---|---|---|---|---|---|---|
| | Instagram / X / TikTok / SEO / 募集サイト | 週◯回 | 試合動画・集合写真・募集告知 | DM / フォーム / LINE / 募集サイト | 回数券・常連枠 | 参加費のみ／スクール併設／物販 |

### チェックポイント
- [ ] プロフィールに「初心者向け」「一人参加」の訴求があるか
- [ ] 募集投稿に料金・持ち物・レベルが明記されているか
- [ ] 予約まで何タップかかるか
- [ ] LINE公式を持っているか（持っていれば友だち追加特典は何か）
- [ ] 参加費以外のマネタイズ（note・ブログ・物販・スクール・協賛）をしているか

## 4. 口コミ・不満の抽出（差別化の種）

| 不満の種類 | 具体的な声（出典） | 発生頻度 | 自分の解決策 |
|---|---|---|---|
| レベル差 | 「経験者ばかりで楽しめなかった」 | | レベル別コート・初心者限定回 |
| 内輪感 | 「常連同士で固まっていて話しかけづらい」 | | 運営がペアを決める・名札 |
| 運営の質 | 「時間がルーズ」「当日まで場所が分からない」 | | 自動リマインド・参加証 |
| 勧誘 | 「別の勧誘目的の人がいた」 | | 勧誘禁止ルールの明記・違反者対応 |
| 価格 | 「この内容でこの値段は高い」 | | 込み料金の明示 |

## 5. ポジショニングマップ

```
                     初心者向け
                        ▲
                        │      ★自分（狙う位置）
                        │      「初心者×一人参加×安心運営」
   低価格 ◀─────────────┼─────────────▶ 高価格
   (〜1,000円)          │             (2,000円〜)
                        │
                        │
                        ▼
                     経験者向け
```

- 縦軸・横軸は「レベル×価格」以外に「頻度×規模」「交流重視×競技重視」でも作ってみる
- **空白地帯**（競合が少ない象限）を見つけて、そこに旗を立てる
